# Designare Feedback Ratings **Designare Feedback Ratings** ist ein leistungsstarkes WordPress-Plugin, mit dem du wertvolles Nutzer-Feedback direkt auf deiner Website sammeln kannst. Es kombiniert ein modernes User Interface mit SEO-Best-Practices, um deine Suchergebnisse in Google durch Rich Snippets (Sterne-Bewertungen) hervorzuheben. ## 🚀 Highlights - **Zwei Bewertungssysteme:** Wähle zwischen einem 5-Sterne-System oder einem 3-stufigen Thumbs-System (Hilfreich/Neutral/Nicht hilfreich). - **SEO-Turbo:** Generiert automatisch valides JSON-LD (Schema.org `AggregateRating`), um die Click-Through-Rate (CTR) in Suchmaschinen zu steigern. - **Echtzeit-Statistiken:** Ein integriertes Admin-Dashboard mit Chart.js visualisiert die Zufriedenheit deiner Leser. - **Dark Mode Support:** Native Unterstützung für helle und dunkle Themes sowie automatische Erkennung der Systemeinstellungen. - **Custom Icons:** Lade eigene SVGs oder Bilder direkt im Backend hoch, um das Widget perfekt an dein Branding anzupassen. ## ✨ Features - **Gutenberg Ready:** Bequemes Einfügen über einen eigenen Block mit Live-Vorschau. - **Vollständig Modular:** Bestimme selbst, auf welchen Post-Types das Widget automatisch erscheinen soll. - **Spam-Schutz inklusive:** Nutzt Honeypot-Felder, LocalStorage und Rate-Limiting (IP-Hash), um Manipulationen zu verhindern. - **E-Mail-Alerts:** Lass dich optional sofort benachrichtigen, wenn ein Beitrag negatives Feedback erhält. - **Design-Kontrolle:** Passe Farben, Eckenabrundungen und Button-Stile (Standard, Minimal, Pill) direkt in den Einstellungen an. - **Datenschutzkonform:** Keine Cookies, keine Speicherung von personenbezogenen Daten (IPs werden nur anonymisiert als Hash für das Limit genutzt). ## 🛠 Installation 1. Lade das Plugin-Verzeichnis in den Ordner `/wp-content/plugins/` hoch. 2. Aktiviere das Plugin im WordPress-Dashboard. 3. Konfiguriere dein System unter **Feedback > Einstellungen**. ## 📖 Verwendung ### Automatisch Aktiviere die Option "Widget automatisch am Ende anzeigen" in den Einstellungen. ### Shortcodes - `[feedback_rating]` – Nutzt das globale Theme aus den Einstellungen. - `[feedback_stars]` – Erzwingt das 5-Sterne-System. - `[feedback_thumbs]` – Erzwingt das Daumen-System. **Parameter:** `show_stats="false"`, `show_share="false"`, `theme="stars/thumbs"`. ### PHP-Template ```php
